# Simple Library System

This is a very easy beginner project for learning basic OOP in Python.

## What we used
This project uses only simple OOP ideas:
- Classes
- Objects
- Constructor
- Functions
- Variables

## Project idea
The program creates a library, adds books, adds members, lets a member borrow a book, and then returns it.

## Classes in the project
- Book: stores the title, author, and book status
- Member: stores the member name and the books they borrowed
- Library: stores all books and members and handles borrowing and returning

## How to run
Open the file in Python and run it:

```python
python library_system.py
```

## Simple summary
This project is made to help beginners understand how real-world systems can be modeled using classes and objects in a simple way.
